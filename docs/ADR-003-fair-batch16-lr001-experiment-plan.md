# ADR-003: 统一 batch=16 / lr0=0.01 公平实验与主创新链记录

**Status:** 主创新链固定为 `F0 -> F1 -> F2 -> D2.1 -> A1 -> B2`。A1 是当前最均衡、overall mAP50-95 最高的关键节点；B2 是加入 P4 Parallel Cross 后的主线终点，用于呈现高层跨模态交互带来的类别收益重分配。F3/F4、D1/D2.2/D2.3/D3、A2、B1/B3-B9 均作为支线消融或诊断证据，不再进入主创新链。\

## 决策摘要：固定主创新链

本文档的叙事与后续论文实验统一围绕以下主创新链展开：

```text
F0：无 P2 neck/head，P3 aux 关闭，P4 使用 A2C2f
  -> F1：加入 plain P2 neck/head
  -> F2：加入 RGB/IR 单模态 P3 auxiliary heads
  -> D2.1：plain P2 fusion 替换为 DMGInit8d@P2
  -> A1：加入 FreAtt@P3
  -> B2：A2C2f@P4 替换为 Parallel Cross A2C2f@P4
```

这条链记录从基础双流检测器到完整多层跨模态模型的结构演进，并不要求每一步单调提高 overall mAP50-95：

- `F0 -> F1`：验证 P2 检测层对较小目标的贡献。
- `F1 -> F2`：验证 P3 单模态辅助监督能否约束新增 P2 路径并恢复 smoke。
- `F2 -> D2.1`：验证 P2 差分放大、共模抑制融合的类别偏向。
- `D2.1 -> A1`：验证 P3 中层频域跨模态交互；这是主链中最明确的整体收益步骤。
- `A1 -> B2`：验证 P4 高层 Parallel Cross；其主要结果是类别收益重分配，而不是 overall 指标提升。

### 主链最终结论

1. **F1/F2 建立了有效的四尺度检测基础。** plain P2 主要改善 fire/person，P3 aux 则修复 smoke 并稳定训练。
2. **D2.1 是机制节点，不是单独性能节点。** DMGInit8d@P2 定义了差分放大、共模抑制的 P2 融合方式，但其单独 overall mAP50-95 与 F2 持平，并牺牲 smoke。
3. **A1 是当前最均衡、overall mAP50-95 最高的主线节点。** FreAtt@P3 为三类同时带来高 IoU 收益，是主链最有说服力的结构增益。
4. **B2 是高层跨模态交互的机制终点。** Parallel Cross@P4 明确提升 fire/person，但以 smoke Recall 和 mAP50-95 为代价，说明高层跨模态交互会改变类别间的优化与决策平衡。
5. **主链最终形成的研究问题不是继续堆叠模块，而是保留 P4 cross 对 fire/person 的收益，同时避免 smoke 的类别特异性退化。**

## 三、D1-D3：DMG 差分放大约束实验

本组实验继续采用第一节公平训练参数，目标是在 P2 保留 DMG 思路的基础上，约束或诱导模块学习“差分放大、共模抑制”的方向。P4 使用 A2C2f，P3 aux-head 默认启用。D1、D2.1、D3 的验证结果来自各实验目录下的 `results1.png`，D2.2 与 D2.3 来自用户验证截图。

D1-D3 的实验含义如下：

- D1（PosAlpha）：约束 DMG 的差分放大系数 `alpha >= 0`，避免模型学成“差分抑制”。
- D2.1（Init8d）：`alpha_init=1.0`，`beta_init=-0.1`。用历史 Exp-8d 的有效趋势初始化 DMG，使其从训练初期就偏向“差分放大 + 共模抑制”。
- D2.2（Init8d-Mid，已弃用）：`alpha_init=1.5`，`beta_init=-0.15`。在 D2.1 基础上提高差分放大与共模抑制强度，用于观察初始化强度敏感性；结果未优于 D2.1，后续不作为保留方案。
- D2.3（Init8d-Strong，已弃用）：`alpha_init=2.0`，`beta_init=-0.3`。进一步提高差分放大与共模抑制强度，用于验证强初始化是否继续带来收益；结果继续下降，后续不作为保留方案。
- D3（In-Sigmoid）：尝试用 InstanceNorm 后的独立 sigmoid 门控替代原始 softmax 选择，但实验显示高 IoU 指标下降，已废弃。

### 4.5 关键实验统一训练趋势分析

为判断“某类目标在训练后期指标下降”是否由某个新模块首次引入，这里统一比较 8 个关键节点的 `results.csv`：F0、F1、F2、D1、D2.1、A1、B2、B8。比较口径统一为：各类别 Recall 从峰值到训练末尾的回落量；并结合 mAP50 / mAP50-95 的变化判断该现象是覆盖率下降，还是高 IoU 定位也同步退化。

#### 4.5.1 Recall 峰值到最终值的回落量

| 实验 | smoke | fire | person |
| -- | --: | --: | --: |
| F0 | -0.02374 | -0.00544 | -0.00402 |
| F1 | **-0.04249** | -0.00929 | -0.01516 |
| F2 | -0.02443 | -0.00660 | -0.00520 |
| D1 | -0.02125 | -0.00723 | -0.00862 |
| D2.1 | **-0.01860** | -0.01144 | -0.00949 |
| A1 | -0.02448 | -0.01160 | **-0.02114** |
| B2 | **-0.03359** | -0.00617 | -0.00432 |
| B8 | **-0.03475** | -0.00823 | -0.00752 |

这张表说明两件事：

1. **smoke 是唯一一个在全部关键实验中都稳定出现明显后期 Recall 回落的类别。** 即使在 F0，smoke Recall 也已回落 `-0.02374`，说明这不是某个后续结构第一次引入的问题，而是基础训练现象。
2. **fire 的回落始终温和，person 则更依赖结构。** fire 基本维持在 `-0.005 ~ -0.012`；person 在 F0/F2/B2 中较轻，但在 F1 与 A1 中会被明显放大。

#### 4.5.2 按模块观察现象如何被放大或缓解

- **F0 -> F1：加入 `plainP2`，但没有 `P3 aux`。** smoke 回落从 `-0.02374` 放大到 `-0.04249`，person 从 `-0.00402` 放大到 `-0.01516`。这是第一个明确恶化点，说明 `plainP2` 如果缺少 `P3 aux` 约束，模型会在后期明显转向更保守的 smoke/person 预测。
- **F1 -> F2：补上 `P3 aux`。** smoke 回落回到 `-0.02443`，person 回到 `-0.00520`，说明 `P3 aux` 明显缓解了 F1 的后期退化。
- **F2 -> D1 -> D2.1：加入 DMG / Init8d。** smoke 回落继续减轻，D2.1 最小，仅 `-0.01860`。这说明 DMG 系列不是问题来源，反而对 smoke 后期稳定性是缓解性的。
- **D2.1 -> A1：加入 `FreAtt@P3`。** smoke 从 `-0.01860` 回到 `-0.02448`，变化有限；但 person 从 `-0.00949` 放大到 `-0.02114`，说明 A1 的主要副作用更偏向 person，而不是 smoke。
- **A1 -> B2/B8：加入 `P4 Parallel Cross`。** smoke 从 `-0.02448` 进一步恶化到 `-0.03359/-0.03475`，而 person 则从 `-0.02114` 改善到 `-0.00432/-0.00752`。这说明 P4 cross 没有首次引入后期退化，但**显著放大了 smoke 的 Recall 回落，同时修复了 person 的后期稳定性**。

#### 4.5.3 结合 mAP50 / mAP50-95 的解释

对 smoke 来说，B2/B8 不仅 Recall 回落更大，`mAP50` 也持续下降，但 `mAP50-95` 仅小幅下降并基本维持平台。这意味着后期训练并非把 smoke 的定位质量整体学坏，而是**逐步放弃困难 smoke，只保留高置信、高 IoU 的较易样本**。

fire 没有呈现同等程度的退化放大；B2/B8 甚至在最终验证里仍保持更强的 fire 表现。person 则说明不同模块会在类别间重新分配收益与稳定性：`FreAtt@P3` 更容易让 person 在后期回落，而 `P4 Parallel Cross` 则把这部分稳定性换了回来。

#### 4.5.4 结论

1. **后期指标下降不是某个模块首次引入的异常，而是基础训练过程中的类别特异性现象。**
2. **smoke 后期 Recall 下降从 F0 就存在，是最统一、最稳定的现象。**
3. **F1 首次把 smoke/person 的后期回落显著放大，证明 `plainP2` 如果没有 `P3 aux` 很容易加剧退化。**
4. **D1 / D2.1 对 smoke 后期稳定性是缓解性的，不是问题来源。**
5. **A1 没有显著加重 smoke 退化，但明显放大了 person 的后期 Recall 回落。**
6. **B2 / B8 才是再次显著放大 smoke 后期 Recall 回落的关键阶段，也就是 `P4 Parallel Cross` 带来的类别收益再分配。**

### 5.1 实验目标、统一训练设置与结构变量

B 系列以 A1 的 `DMGInit8d@P2 + FreAtt@P3 + P3 aux` 为基础，研究 P4/P5 高层跨模态注意力及其轻量化、残差约束、分支深度和多阶段特征聚合能否改善验证集泛化。除下表显式列出的变量外，均继承 A1 与 B2 的设置。

Parallel Cross A2C2f 将每个模态拆分为 self 与 cross 两条 `C/2` 分支。cross 分支以另一模态进入模块时的固定 cross 特征作为 K/V；默认将 `self_in/cross_in/self_out/cross_out` 四路特征拼接，经 `2C -> C` 的 `cv2` 投影后，由 learnable gamma 残差注入原特征。`cross_scale_rgb` 控制 IR guide 到 RGB query 的 cross delta，`cross_scale_ir` 控制 RGB guide 到 IR query 的 cross delta。B9 进一步加入中间阶段特征，并使用 `3C -> C` 投影。

### 5.4 结构诊断

B1 的 pcross 会替换原 A2C2f 的多阶段特征细化拓扑，而不是在原拓扑旁路轻量添加 cross attention。B1 同时改变特征流数量、concat 语义、残差形式与跨模态耦合方式，因此变量范围较大。

B1 `last.pt` 的 P4/P5 gamma 分别为 RGB `+0.21155/+0.37012`、IR `-0.20618/-0.44434`。forward hook 显示 P5 IR 残差注入强度约为原特征范数的 53%，是明显的高层负向修正。运行时缩放或关闭 P5 gamma 会进一步降低 mAP50-95；结合 B2 移除 P5 后明显恢复，说明 P5 cross 是 B1 的主要负贡献来源。

B3 证明问题不是 cross MLP 宽度过大导致的简单容量过拟合。B4 则证明单独减弱一个方向的 cross delta 也不能解决问题，并会削弱 fire 所需的跨模态补充。

### 5.5 B 系列结论与主线定位

1. **固定主创新链以 B2 作为结构终点，但 A1 仍是当前最均衡、overall mAP50-95 最高的节点。** B2 用于证明 P4 Parallel Cross 会提升 fire/person，同时牺牲 smoke；这项类别收益重分配本身是后续机制研究的依据。
2. **B8 epoch190 是最接近 A1 的 B 系列支线节点。** A1 与 B8 的 all mAP50-95 分别为 `0.64123/0.64117`，差值仅 `-0.00006`；但 B8 smoke 仍比 A1 低 `0.00725`。B8 不进入固定主创新链。
3. **B2 取得 B 系列最高 fire mAP50-95 `0.59954`，且结构比 B8 更简单。** B8 通过增加 self/cross 深度将 overall mAP50-95 提高到 `0.64117`，但没有解决 smoke 损失。
4. **B1、B3-B7 均弃用。** P5 cross、缩窄 cross MLP、非对称 scale、低学习率加 DropPath、正值有界 gamma，以及仅增加 self 深度均未超过 B2/B8。B7 的 all Precision 虽最高，但 Recall 和 overall mAP50-95 明显下降。
5. **B9 也不保留。** 恢复 P4 self/cross 中间阶段特征聚合后，B9 的 all/smoke/fire mAP50-95 分别为 `0.63882/0.73387/0.59181`，同时低于 B8 的 `0.64117/0.73669/0.59911` 和 B2 的 `0.64081/0.73570/0.59954`，说明 B2/B8 的 smoke 损失并非主要来自缺少原始 A2C2f 的中间阶段 concat。

1. **B2/B8/B9 都存在 smoke 后期 Recall 持续下降现象。** 其回落量分别为 `-0.03359/-0.03475/-0.03046`，明显大于同实验中 fire/person 的回落幅度。
2. **B 系列 smoke 的共同模式是：Recall 和 mAP50 持续下降，但 mAP50-95 基本保持平台。** 这说明后期训练主要保留了高 IoU、高置信度的较易样本，同时逐步放弃困难 smoke。
3. **B9 没有改变这一模式。** 恢复中间阶段 concat 后，smoke Recall 仍在后期明显回落，说明该问题不是简单由 P4 原始多阶段聚合缺失单独造成的。

### 5.6 B2 相对 A1 的 smoke 逐层 neck 诊断

为定位 B2 smoke 漏检发生在 neck 的哪一段，这里对 `A1 检出、B2 漏检` 的 182 个 smoke 目标做逐层跟踪，并用 182 个按尺寸匹配的 `A1/B2 都检出` 目标作为对照。统计位置为 neck 的六个关键节点：

- `11`: `topdown_p4`
- `14`: `topdown_p3`
- `17`: `topdown_p2`
- `20`: `bottomup_p3`
- `23`: `bottomup_p4`
- `26`: `bottomup_p5`

统计指标主要看 GT box 内的 `local_contrast`，并辅以 `roi_peak`。结果表明，B2 不是在 backbone P4 一次性把 smoke 学坏，而是在 neck 的 top-down / bottom-up 传递中把烟雾特征重组得更尖、更窄，但不够稳，最终导致分类头置信度被压低。

#### 5.6.1 漏检组的逐层变化

在 `A1 检出、B2 漏检` 的 182 个样本上，B2 相对 A1 的 `local_contrast` 中位数变化如下：

| neck 节点      |  A1 中位数 |  B2 中位数 |    B2-A1 |
| ------------ | ------: | ------: | -------: |
| topdown\_p4  | 1.03073 | 1.01768 | -0.01306 |
| topdown\_p3  | 1.10121 | 1.07390 | -0.02731 |
| topdown\_p2  | 1.08309 | 1.09561 | +0.01252 |
| bottomup\_p3 | 1.16072 | 1.14868 | -0.01204 |
| bottomup\_p4 | 1.11724 | 1.09966 | -0.01758 |
| bottomup\_p5 | 1.03928 | 1.02298 | -0.01630 |

关键现象只有两点：`topdown_p4 -> topdown_p3` 是第一段明显下滑点，`bottomup_p3 -> bottomup_p5` 则持续放大差距。`roi_peak` 也呈现同样走势，说明 B2 更容易把 smoke 特征压成尖锐但不稳定的局部响应，而不是完整区域证据。

#### 5.6.2 对照组的逐层变化

在 `A1 与 B2 都检出` 的对照组上，B2 反而能把 neck 的中高层特征做得更强，尤其是 `topdown_p2` 和 `bottomup_p3`：

| neck 节点      |  A1 中位数 |  B2 中位数 |    B2-A1 |
| ------------ | ------: | ------: | -------: |
| topdown\_p4  | 1.03590 | 1.03362 | -0.00228 |
| topdown\_p3  | 1.13065 | 1.16114 | +0.03049 |
| topdown\_p2  | 1.09049 | 1.19491 | +0.10443 |
| bottomup\_p3 | 1.22505 | 1.28491 | +0.05986 |
| bottomup\_p4 | 1.16960 | 1.19811 | +0.02851 |
| bottomup\_p5 | 1.07466 | 1.06352 | -0.01114 |

对照组说明 B2 不是整体能力变差，而是更容易在低对比、易漏检 smoke 上破坏稳定语义，因此总体分数接近 A1，但 smoke recall 更低。

#### 5.6.3 结论

1. **B2 的 smoke 问题主要出在 neck 传播与重组，而不是 backbone P4 激活不足。**
2. **主要损失发生在 `topdown_p3` 之后，并在 `bottomup_p4/p5` 放大。**
3. **B2 对正常 smoke 更强，但对低对比、32-128px 烟雾更容易产生高峰值、低稳定性的碎片化响应。**
