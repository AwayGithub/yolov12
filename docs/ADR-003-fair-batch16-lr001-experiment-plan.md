## 三、D1-D3：DMG 差分放大约束实验

本组实验继续采用第一节公平训练参数，目标是在 P2 保留 DMG 思路的基础上，约束或诱导模块学习“差分放大、共模抑制”的方向。P4 使用 A2C2f，P3 aux-head 默认启用。D1、D2.1、D3 的验证结果来自各实验目录下的 `results1.png`，D2.2 与 D2.3 来自用户验证截图。

D1-D3 的实验含义如下：

- D1（PosAlpha）：约束 DMG 的差分放大系数 `alpha >= 0`，避免模型学成“差分抑制”。
- D2.1（Init8d）：`alpha_init=1.0`，`beta_init=-0.1`。用历史 Exp-8d 的有效趋势初始化 DMG，使其从训练初期就偏向“差分放大 + 共模抑制”。
- D2.2（Init8d-Mid，已弃用）：`alpha_init=1.5`，`beta_init=-0.15`。在 D2.1 基础上提高差分放大与共模抑制强度，用于观察初始化强度敏感性；结果未优于 D2.1，后续不作为保留方案。
- D2.3（Init8d-Strong，已弃用）：`alpha_init=2.0`，`beta_init=-0.3`。进一步提高差分放大与共模抑制强度，用于验证强初始化是否继续带来收益；结果继续下降，后续不作为保留方案。
- D3（In-Sigmoid）：尝试用 InstanceNorm 后的独立 sigmoid 门控替代原始 softmax 选择，但实验显示高 IoU 指标下降，已废弃。

D2 系列的最终结论是：只有 D2.1（`alpha_init=1.0`、`beta_init=-0.1`）取得有效且稳定的收益，是 D 系列最终保留方案。相对 F2，D2.1 的 all mAP50-95 基本持平（-0.00003），但 fire/person 的 mAP50-95 分别提升 +0.00264/+0.00258；相对 F0，D2.1 的 all/fire/person mAP50-95 分别提升 +0.01218/+0.01489/+0.02239。也就是说，F0 对比证明完整结构堆叠明显有效，F2 对比则说明 Init8d 的主要边际价值集中在 fire/person，而不是 smoke 或 all 总分。

从任务优先级看，本项目更关注 fire/person 关键目标，尤其是火焰定位质量和人员目标稳定检出。在该口径下，D2.1 是当前 D 系列最合适的保留结果；D2.2 与 D2.3 的价值主要在于证明 Init8d 存在强度敏感性，不能简单通过增大 `alpha_init` 或降低 `beta_init` 获得更好结果，后续实验与报告不再将其作为候选主线。

D3（In-Sigmoid）不适合作为后续主线。虽然 D3 的 P/R 和 mAP50 多数高于 F2，但 all、fire、person 的 mAP50-95 均低于 F2，说明该结构更像提升粗检出能力，却损伤高 IoU 定位质量。

| B3 | 0.14674 / 0.14888 / 0.75530 | 1.16585 / 0.59311 / 1.80983 | 1.01911 | 0.44423 | 1.05453 | **2.51787** | **-0.00024** |

按 loss gap 排序，B1 过拟合最重，B2 最轻，B3 位于二者之间。B3 将 cross MLP ratio 降至 1.0 后，训练损失与 B2 几乎相同，但验证 box/cls/dfl loss 均略高，gap 总和比 B2 增加 0.01721，因此没有缓解 B2 的过拟合。B3 的 best-to-last 回落最小，说明后期平台更稳定，但稳定在更低的验证性能水平；其训练曲线 best all mAP50-95 为 0.63818（epoch 190），last 为 0.63794，本次 `best.pt` 独立复验为 0.63686。

结构对照显示，B1 的 pcross 并不是在原 A2C2f 旁路上轻量增加 cross attention，而是替换了原 A2C2f 的多阶段特征细化拓扑。A1 中 P4/P5 的原始 A2C2f 分别为 `cv1: 128->64, cv2: 192->128` 与 `cv1: 256->128, cv2: 384->256`，每层 `m_len=2` 且每个 stage 内含 2 个 ABlock，因此每个层级共 4 个 ABlock，并通过 `cv1(x), m0(...), m1(...)` 三路 concat 输出。B1 中 P4/P5 被替换为 `cv1_rgb/ir: C->C`、split 后 self/cross 两条 `C/2` 分支、`cv2_rgb/ir: 2C->C`，每条 self/cross 分支各 2 个 ABlock，最后以 `x + gamma * delta` 输出。也就是说，B1 同时改变了特征流数量、concat 语义、残差形式与跨模态耦合方式，变量比“仅加入 cross attention”更大。

从 `last.pt` 中读取到的最终 gamma 为：

| 层级 | gamma\_rgb | gamma\_ir |
| -- | ---------: | --------: |
| P4 |   +0.21155 |  -0.20618 |
| P5 |   +0.37012 |  -0.44434 |

在 16 张验证图像上做 forward hook 统计，残差注入强度（`||out - x|| / ||x||`）约为：

| 层级 | RGB 分支 |  IR 分支 |
| -- | -----: | -----: |
| P4 | 0.2119 | 0.2769 |
| P5 | 0.3700 | 0.5312 |

P5 尤其是 IR 分支的残差改变量已达到原特征范数的约 53%，且 gamma 为明显负值。这表明 B1 的 P5 cross 分支不再是轻量补充，而是在高层语义处对 IR 分支进行强负向修正。结合 B1 的 recall、mAP50、smoke mAP50-95 均显著低于 A1，可判断该结构大概率引入了高层跨模态扰动：对 person 有一定补充，但破坏了 smoke/fire 的稳定语义聚合。

进一步拆分 self/cross 分支后，在 32 张验证图像上的统计显示：P4 的 RGB/IR self 分支相对输入改变量约为 3.25/4.57，cross 分支约为 3.37/4.41；P5 的 RGB/IR self 分支约为 3.68/3.84，cross 分支约为 3.62/4.66。self 输出与 cross 输出的 cosine similarity 接近 0（P4 RGB 0.0007、P4 IR 0.0008、P5 RGB -0.0041、P5 IR 0.0095），说明两条分支学到的表征几乎正交。该现象本身不必然错误，但在高层语义位置会显著增加 `cv2` 融合负担：模型需要同时整合原始分支、self 强变换分支、cross 强变换分支，并通过单一 gamma 控制整体残差幅度，容易出现训练集适配但验证泛化变差。

额外的运行时 gamma 消融也说明，训练后的 B1 已与 P5 cross 分支发生强耦合，不能在推理阶段简单关闭修复：在 `last.pt` 上仅将 P5 gamma 缩放到 0.5 时，all mAP50-95 为 0.63179；缩放到 0.25 时为 0.62151；直接置零时为 0.60036。B2 的 P4-only 结构级消融进一步验证，P5 cross 是 B1 的主要负贡献来源。

### 5.6 B 系列结论

B1 不作为后续主线。其结果说明，在 A1 已具备 `DMGInit8d@P2 + FreAtt@P3` 的低/中层增强后，继续在 P4/P5 同时加入 parallel cross A2C2f 会带来额外参数量与更强训练集拟合，但验证集收益不足，整体指标退回 F2/D2.1 水平。B2 移除 P5 cross 后，all mAP50-95 从 B1 的 0.63552 恢复到 0.64081，fire mAP50-95 提升到 0.59954，验证了 P5 是 B1 的主要负贡献来源。

B2 保留为 P4-only 高层跨模态对照，但不替代 A1：其 all mAP50-95 仍比 A1 低 0.00042，且 smoke 低 0.00824；同时 epoch 200 的验证分类与 DFL 损失仍高于 A1，说明 P4 cross 仍存在一定过拟合。

B3 不作为后续主线。将跨模态 MLP ratio 从 2.0 降至 1.0 虽减少 33,280 个参数，并提高 recall 与 mAP50，但单次复验 all mAP50-95 比 B2 下降 0.00395，fire mAP50-95 下降 0.00769，且 epoch 200 loss gap 比 B2 更大。说明当前问题不是 cross MLP 宽度过大导致的简单容量过拟合；继续优化应优先考虑 gamma 约束、DropPath、模块低学习率或更小的跨模态残差注入，而不是继续缩窄 MLP。
