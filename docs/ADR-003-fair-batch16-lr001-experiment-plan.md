## 三、D1-D3：DMG 差分放大约束实验

本组实验继续采用第一节公平训练参数，目标是在 P2 保留 DMG 思路的基础上，约束或诱导模块学习“差分放大、共模抑制”的方向。P4 使用 A2C2f，P3 aux-head 默认启用。D1、D2.1、D3 的验证结果来自各实验目录下的 `results1.png`，D2.2 与 D2.3 来自用户验证截图。

D1-D3 的实验含义如下：

- D1（PosAlpha）：约束 DMG 的差分放大系数 `alpha >= 0`，避免模型学成“差分抑制”。
- D2.1（Init8d）：`alpha_init=1.0`，`beta_init=-0.1`。用历史 Exp-8d 的有效趋势初始化 DMG，使其从训练初期就偏向“差分放大 + 共模抑制”。
- D2.2（Init8d-Mid，已弃用）：`alpha_init=1.5`，`beta_init=-0.15`。在 D2.1 基础上提高差分放大与共模抑制强度，用于观察初始化强度敏感性；结果未优于 D2.1，后续不作为保留方案。
- D2.3（Init8d-Strong，已弃用）：`alpha_init=2.0`，`beta_init=-0.3`。进一步提高差分放大与共模抑制强度，用于验证强初始化是否继续带来收益；结果继续下降，后续不作为保留方案。
- D3（In-Sigmoid）：尝试用 InstanceNorm 后的独立 sigmoid 门控替代原始 softmax 选择，但实验显示高 IoU 指标下降，已废弃。

D2 系列的最终结论是：只有 D2.1（`alpha_init=1.0`、`beta_init=-0.1`）取得有效且稳定的收益，是 D 系列最终保留方案。相对 F2，D2.1 的 all mAP50-95 基本持平（-0.00003），但 fire/person 的 mAP50-95 分别提升 +0.00264/+0.00258；相对 F0，D2.1 的 all/fire/person mAP50-95 分别提升 +0.01218/+0.01489/+0.02239。也就是说，F0 对比证明完整结构堆叠明显有效，F2 对比则说明 Init8d 的主要边际价值集中在 fire/person，而不是 smoke 或 all 总分。

从任务优先级看，本项目更关注 fire/person 关键目标，尤其是火焰定位质量和人员目标稳定检出。在该口径下，D2.1 是当前 D 系列最合适的保留结果；D2.2 与 D2.3 的价值主要在于证明 Init8d 存在强度敏感性，不能简单通过增大 `alpha_init` 或降低 `beta_init` 获得更好结果，后续实验与报告不再将其作为候选主线。

D3（In-Sigmoid）不适合作为后续主线。虽然 D3 的 P/R 和 mAP50 多数高于 F2，但 all、fire、person 的 mAP50-95 均低于 F2，说明该结构更像提升粗检出能力，却损伤高 IoU 定位质量。

## 五、B 系列：A1 + Parallel Cross A2C2f 高层跨模态注意力实验

### 5.1 实验目标与统一定义

B 系列以 A1 的 `DMGInit8d@P2 + FreAtt@P3 + P3 aux` 为基础，研究 P4/P5 高层跨模态注意力及其轻量化、残差约束能否改善验证集泛化。

Parallel Cross A2C2f 将每个模态拆分为 self 与 cross 两条 `C/2` 分支。cross 分支以另一模态的原始 cross 特征作为 K/V，四路 `self_in/cross_in/self_out/cross_out` 拼接后经 `cv2` 输出，并由 learnable gamma 残差注入原特征。B4 进一步只缩放 cross transformation delta，不缩放原始分支特征。

### 5.5 结构诊断

B1 的 pcross 会替换原 A2C2f 的多阶段特征细化拓扑，而不是在原拓扑旁路轻量添加 cross attention。B1 同时改变特征流数量、concat 语义、残差形式与跨模态耦合方式，因此变量范围较大。

B1 `last.pt` 的 P4/P5 gamma 分别为 RGB `+0.21155/+0.37012`、IR `-0.20618/-0.44434`。forward hook 显示 P5 IR 残差注入强度约为原特征范数的 53%，是明显的高层负向修正。运行时缩放或关闭 P5 gamma 会进一步降低 mAP50-95；结合 B2 移除 P5 后明显恢复，说明 P5 cross 是 B1 的主要负贡献来源。

B3 证明问题不是 cross MLP 宽度过大导致的简单容量过拟合。B4 则证明单独减弱一个方向的 cross delta 也不能解决问题，并会削弱 fire 所需的跨模态补充。

### 5.6 B 系列结论

1. **主线仍保留 A1。** A1 的 all mAP50-95 为 0.64123，仍是当前关键节点最优方案。
2. **B2 保留为 P4-only 对照。** B2 距 A1 仅 -0.00042，并取得 B 系列最高 fire mAP50-95，但仍存在一定过拟合且 smoke 低于 A1。
3. **B1、B3、B4 均弃用。** B1 的 P5 cross 扰动过强；B3 缩窄 cross MLP 后高 IoU 定位退化；B4 的非对称 cross residual scale 只带来极小 smoke 收益，却损失 fire 与总体 recall。
4. **后续不再优先调整 cross MLP 宽度或单向 scale。** 若继续探索，应考虑不替换原 A2C2f 拓扑的旁路 cross attention、模块低学习率、DropPath 或更明确的正则约束。


### 5.7 B5/B6 实施计划

B5、B6 均从 B2 独立派生，保留 P4-only Parallel Cross、cross MLP ratio=2.0、gamma init=0.01、固定 cross scale=1.0，并使用 `train.py`、RGBT-3M 全量数据、batch=16、200 epoch、每 2 epoch 验证一次。

| 实验 | 保存目录 | 相对 B2 的唯一主要变量 | 目的 | 状态 |
| -- | -- | -- | -- | -- |
| B5 | `runs/detect/train5` | cross/gamma LR multiplier=0.1；双向共享 per-sample DropPath=0.05 | 降低跨模态分支拟合速度并随机正则化 cross delta | 训练中 |
| B6 | `runs/detect/train6` | `gamma=0.35*sigmoid(gamma_logit)`，固定正值有界 gamma | 阻止 gamma 变为负值或无限增大，约束跨模态残差注入 | 训练中 |

B5 的 DropPath 只作用于 `cross_out-cross_in`，两条模态方向共享同一个样本级 mask，不丢弃原始 cross 输入。B6 不叠加 B5 的 DropPath 或低学习率，以便独立判断正值有界 gamma 的效果。
