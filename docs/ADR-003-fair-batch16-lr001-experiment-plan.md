# ADR-003: 统一 batch=16 / lr0=0.01 公平实验与主创新链记录

**Status:** 主创新链固定为 `F0 -> F1 -> F2 -> D2.1 -> A1 -> B2`。A1 是当前最均衡、overall mAP50-95 最高的关键节点；B2 是加入 P4 Parallel Cross 后的主线终点，用于呈现高层跨模态交互带来的类别收益重分配。F3/F4、D1/D2.2/D2.3/D3、A2、B1/B3-B9 均作为支线消融或诊断证据，不再进入主创新链。\

## 决策摘要：固定主创新链

本文档的叙事与后续论文实验统一围绕以下主创新链展开：

```text
F0：无 P2 neck/head，P3 aux 关闭，P4 使用 A2C2f
  -> F1：加入 plain P2 neck/head
  -> F2：加入 RGB/IR 单模态 P3 auxiliary heads
  -> D2.1：plain P2 fusion 替换为 DMGInit8d@P2
  -> A1：加入 FreAtt@P3
  -> B2：A2C2f@P4 替换为 Parallel Cross A2C2f@P4
```

这条链记录从基础双流检测器到完整多层跨模态模型的结构演进，并不要求每一步单调提高 overall mAP50-95：

- `F0 -> F1`：验证 P2 检测层对较小目标的贡献。
- `F1 -> F2`：验证 P3 单模态辅助监督能否约束新增 P2 路径并恢复 smoke。
- `F2 -> D2.1`：验证 P2 差分放大、共模抑制融合的类别偏向。
- `D2.1 -> A1`：验证 P3 中层频域跨模态交互；这是主链中最明确的整体收益步骤。
- `A1 -> B2`：验证 P4 高层 Parallel Cross；其主要结果是类别收益重分配，而不是 overall 指标提升。

### 主链最终结论

1. **F1/F2 建立了有效的四尺度检测基础。** plain P2 主要改善 fire/person，P3 aux 则修复 smoke 并稳定训练。
2. **D2.1 是机制节点，不是单独性能节点。** DMGInit8d\@P2 定义了差分放大、共模抑制的 P2 融合方式，但其单独 overall mAP50-95 与 F2 持平，并牺牲 smoke。
3. **A1 是当前最均衡、overall mAP50-95 最高的主线节点。** FreAtt\@P3 为三类同时带来高 IoU 收益，是主链最有说服力的结构增益。
4. **B2 是高层跨模态交互的机制终点。** Parallel Cross\@P4 明确提升 fire/person，但以 smoke Recall 和 mAP50-95 为代价，说明高层跨模态交互会改变类别间的优化与决策平衡。
5. **主链最终形成的研究问题不是继续堆叠模块，而是保留 P4 cross 对 fire/person 的收益，同时避免 smoke 的类别特异性退化。**

## 三、D1-D3：DMG 差分放大约束实验

本组实验继续采用第一节公平训练参数，目标是在 P2 保留 DMG 思路的基础上，约束或诱导模块学习“差分放大、共模抑制”的方向。P4 使用 A2C2f，P3 aux-head 默认启用。D1、D2.1、D3 的验证结果来自各实验目录下的 `results1.png`，D2.2 与 D2.3 来自用户验证截图。

D1-D3 的实验含义如下：

- D1（PosAlpha）：约束 DMG 的差分放大系数 `alpha >= 0`，避免模型学成“差分抑制”。
- D2.1（Init8d）：`alpha_init=1.0`，`beta_init=-0.1`。用历史 Exp-8d 的有效趋势初始化 DMG，使其从训练初期就偏向“差分放大 + 共模抑制”。
- D2.2（Init8d-Mid，已弃用）：`alpha_init=1.5`，`beta_init=-0.15`。在 D2.1 基础上提高差分放大与共模抑制强度，用于观察初始化强度敏感性；结果未优于 D2.1，后续不作为保留方案。
- D2.3（Init8d-Strong，已弃用）：`alpha_init=2.0`，`beta_init=-0.3`。进一步提高差分放大与共模抑制强度，用于验证强初始化是否继续带来收益；结果继续下降，后续不作为保留方案。
- D3（In-Sigmoid）：尝试用 InstanceNorm 后的独立 sigmoid 门控替代原始 softmax 选择，但实验显示高 IoU 指标下降，已废弃。

### 4.5 关键实验统一训练趋势分析

为判断“某类目标在训练后期指标下降”是否由某个新模块首次引入，这里统一比较 8 个关键节点的 `results.csv`：F0、F1、F2、D1、D2.1、A1、B2、B8。比较口径统一为：各类别 Recall 从峰值到训练末尾的回落量；并结合 mAP50 / mAP50-95 的变化判断该现象是覆盖率下降，还是高 IoU 定位也同步退化。

#### 4.5.1 Recall 峰值到最终值的回落量

| 实验   |        smoke |     fire |       person |
| ---- | -----------: | -------: | -----------: |
| F0   |     -0.02374 | -0.00544 |     -0.00402 |
| F1   | **-0.04249** | -0.00929 |     -0.01516 |
| F2   |     -0.02443 | -0.00660 |     -0.00520 |
| D1   |     -0.02125 | -0.00723 |     -0.00862 |
| D2.1 | **-0.01860** | -0.01144 |     -0.00949 |
| A1   |     -0.02448 | -0.01160 | **-0.02114** |
| B2   | **-0.03359** | -0.00617 |     -0.00432 |
| B8   | **-0.03475** | -0.00823 |     -0.00752 |

这张表说明两件事：

1. **smoke 是唯一一个在全部关键实验中都稳定出现明显后期 Recall 回落的类别。** 即使在 F0，smoke Recall 也已回落 `-0.02374`，说明这不是某个后续结构第一次引入的问题，而是基础训练现象。
2. **fire 的回落始终温和，person 则更依赖结构。** fire 基本维持在 `-0.005 ~ -0.012`；person 在 F0/F2/B2 中较轻，但在 F1 与 A1 中会被明显放大。

#### 4.5.2 按模块观察现象如何被放大或缓解

- **F0 -> F1：加入** **`plainP2`，但没有** **`P3 aux`。** smoke 回落从 `-0.02374` 放大到 `-0.04249`，person 从 `-0.00402` 放大到 `-0.01516`。这是第一个明确恶化点，说明 `plainP2` 如果缺少 `P3 aux` 约束，模型会在后期明显转向更保守的 smoke/person 预测。
- **F1 -> F2：补上** **`P3 aux`。** smoke 回落回到 `-0.02443`，person 回到 `-0.00520`，说明 `P3 aux` 明显缓解了 F1 的后期退化。
- **F2 -> D1 -> D2.1：加入 DMG / Init8d。** smoke 回落继续减轻，D2.1 最小，仅 `-0.01860`。这说明 DMG 系列不是问题来源，反而对 smoke 后期稳定性是缓解性的。
- **D2.1 -> A1：加入** **`FreAtt@P3`。** smoke 从 `-0.01860` 回到 `-0.02448`，变化有限；但 person 从 `-0.00949` 放大到 `-0.02114`，说明 A1 的主要副作用更偏向 person，而不是 smoke。
- **A1 -> B2/B8：加入** **`P4 Parallel Cross`。** smoke 从 `-0.02448` 进一步恶化到 `-0.03359/-0.03475`，而 person 则从 `-0.02114` 改善到 `-0.00432/-0.00752`。这说明 P4 cross 没有首次引入后期退化，但**显著放大了 smoke 的 Recall 回落，同时修复了 person 的后期稳定性**。

#### 4.5.3 结合 mAP50 / mAP50-95 的解释

对 smoke 来说，B2/B8 不仅 Recall 回落更大，`mAP50` 也持续下降，但 `mAP50-95` 仅小幅下降并基本维持平台。这意味着后期训练并非把 smoke 的定位质量整体学坏，而是**逐步放弃困难 smoke，只保留高置信、高 IoU 的较易样本**。

fire 没有呈现同等程度的退化放大；B2/B8 甚至在最终验证里仍保持更强的 fire 表现。person 则说明不同模块会在类别间重新分配收益与稳定性：`FreAtt@P3` 更容易让 person 在后期回落，而 `P4 Parallel Cross` 则把这部分稳定性换了回来。

#### 4.5.4 结论

1. **后期指标下降不是某个模块首次引入的异常，而是基础训练过程中的类别特异性现象。**
2. **smoke 后期 Recall 下降从 F0 就存在，是最统一、最稳定的现象。**
3. **F1 首次把 smoke/person 的后期回落显著放大，证明** **`plainP2`** **如果没有** **`P3 aux`** **很容易加剧退化。**
4. **D1 / D2.1 对 smoke 后期稳定性是缓解性的，不是问题来源。**
5. **A1 没有显著加重 smoke 退化，但明显放大了 person 的后期 Recall 回落。**
6. **B2 / B8 才是再次显著放大 smoke 后期 Recall 回落的关键阶段，也就是** **`P4 Parallel Cross`** **带来的类别收益再分配。**

## 五、B 系列：A1 + Parallel Cross A2C2f 高层跨模态注意力实验

### 5.1 实验目标、统一训练设置与结构变量

B 系列以 A1 的 `DMGInit8d@P2 + FreAtt@P3 + P3 aux` 为基础，研究 P4/P5 高层跨模态注意力及其轻量化、残差约束、分支深度和多阶段特征聚合能否改善验证集泛化。除下表显式列出的变量外，均继承 A1 与 B2 的设置。

Parallel Cross A2C2f 将每个模态拆分为 self 与 cross 两条 `C/2` 分支。cross 分支以另一模态进入模块时的固定 cross 特征作为 K/V；默认将 `self_in/cross_in/self_out/cross_out` 四路特征拼接，经 `2C -> C` 的 `cv2` 投影后，由 learnable gamma 残差注入原特征。`cross_scale_rgb` 控制 IR guide 到 RGB query 的 cross delta，`cross_scale_ir` 控制 RGB guide 到 IR query 的 cross delta。B9 进一步加入中间阶段特征，并使用 `3C -> C` 投影。

### 5.3 结构诊断

B1 的 pcross 会替换原 A2C2f 的多阶段特征细化拓扑，而不是在原拓扑旁路轻量添加 cross attention。B1 同时改变特征流数量、concat 语义、残差形式与跨模态耦合方式，因此变量范围较大。

B1 `last.pt` 的 P4/P5 gamma 分别为 RGB `+0.21155/+0.37012`、IR `-0.20618/-0.44434`。forward hook 显示 P5 IR 残差注入强度约为原特征范数的 53%，是明显的高层负向修正。运行时缩放或关闭 P5 gamma 会进一步降低 mAP50-95；结合 B2 移除 P5 后明显恢复，说明 P5 cross 是 B1 的主要负贡献来源。

B3 证明问题不是 cross MLP 宽度过大导致的简单容量过拟合。B4 则证明单独减弱一个方向的 cross delta 也不能解决问题，并会削弱 fire 所需的跨模态补充。

### 5.4 B 系列结论与主线定位

1. **固定主创新链以 B2 作为结构终点，但 A1 仍是当前最均衡、overall mAP50-95 最高的节点。** B2 用于证明 P4 Parallel Cross 会提升 fire/person，同时牺牲 smoke；这项类别收益重分配本身是后续机制研究的依据。
2. **B8 epoch190 是最接近 A1 的 B 系列支线节点。** A1 与 B8 的 all mAP50-95 分别为 `0.64123/0.64117`，差值仅 `-0.00006`；但 B8 smoke 仍比 A1 低 `0.00725`。B8 不进入固定主创新链。
3. **B2 取得 B 系列最高 fire mAP50-95** **`0.59954`，且结构比 B8 更简单。** B8 通过增加 self/cross 深度将 overall mAP50-95 提高到 `0.64117`，但没有解决 smoke 损失。
4. **B1、B3-B7 均弃用。** P5 cross、缩窄 cross MLP、非对称 scale、低学习率加 DropPath、正值有界 gamma，以及仅增加 self 深度均未超过 B2/B8。B7 的 all Precision 虽最高，但 Recall 和 overall mAP50-95 明显下降。
5. **B9 也不保留。** 恢复 P4 self/cross 中间阶段特征聚合后，B9 的 all/smoke/fire mAP50-95 分别为 `0.63882/0.73387/0.59181`，同时低于 B8 的 `0.64117/0.73669/0.59911` 和 B2 的 `0.64081/0.73570/0.59954`，说明 B2/B8 的 smoke 损失并非主要来自缺少原始 A2C2f 的中间阶段 concat。

| `>=256` | 11 |

这些额外漏检不只集中在小目标。`32-64` 与 `64-128` 最多，`128-256` 也有 41 个，因此 B2 的 smoke 损失不能简单解释为“小目标检测头能力不足”。

B2 的漏检原因如下：

| B2 reason | 数量 |
| -- | --: |
| low_confidence | 111 |
| no_response | 45 |
| poor_localization | 25 |
| class_confusion | 1 |

主因是 `low_confidence`。在这 182 个实例上，A1/B2 的最佳 smoke 匹配统计为：

| 指标 | A1 检出侧 | B2 漏检侧 |
| -- | --: | --: |
| best smoke IoU mean | 0.7596 | 0.5161 |
| best smoke IoU median | 0.7781 | 0.6468 |
| best smoke conf mean | 0.7787 | 0.2515 |
| best smoke conf median | 0.8930 | 0.0429 |

关键点是：B2 的 median IoU 仍有 `0.6468`，但 median conf 只有 `0.0429`。这说明很多 B2 漏检并非完全找不到区域，而是 smoke 类别响应被压低到阈值以下。

#### 6.2.2 Head 层级与 smoke 响应坍缩

A1 对这 182 个实例的 dominant head 分布如下：

| A1 dominant head | 数量 |
| -- | --: |
| p2 | 61 |
| p3 | 56 |
| p4 | 55 |
| p5 | 10 |

按尺寸看，p2 主要对应 `<32/32-64`，p3 对应 `32-128`，p4 对应 `64-256`，p5 对应大目标。这说明 B2 的额外漏检横跨 p2/p3/p4，而不是单一 head 失效。

更关键的是，同一 GT 区域在 head 侧的 smoke max 大幅下降：

| 指标 | 均值 | 中位数 | 最小值 | 最大值 |
| -- | --: | --: | --: | --: |
| A1 head smoke max | 0.8156 | 0.8978 | 0.2591 | 0.9690 |
| B2 same-head smoke max | 0.1130 | 0.0077 | 0.0000 | 0.9874 |
| head_delta | -0.7026 | -0.8311 | -0.9649 | 0.2685 |

这是当前最直接的机制证据：B2 在 A1 能稳定检出的 smoke 上，最终 head 的 smoke 类别响应不是轻微下降，而是发生明显坍缩。

与 182 个 `A1/B2 都检出` 的对照组相比，head smoke max 的 `log_ratio(B2/A1)` 差异如下：

| head smoke max log_ratio(B2/A1) | A1 检出/B2 漏检 median | both-hit control median | 差值 |
| -- | --: | --: | --: |
| p2 | -0.6760 | 0.0151 | -0.6910 |
| p3 | -1.5318 | 0.0096 | -1.5414 |
| p4 | -1.0445 | -0.0025 | -1.0419 |
| p5 | 0.0059 | 0.0032 | 0.0027 |

p3 的下降最明显，其次是 p4 和 p2；p5 不是主要矛盾。

#### 6.2.3 Neck 与 P4 路径中的特征变化

在 neck 层面，A1 检出/B2 漏检组与 both-hit 对照组呈现明显分化。

| neck ROI peak log_ratio(B2/A1) | A1 检出/B2 漏检 median | both-hit control median | 差值 |
| -- | --: | --: | --: |
| p2 | 0.2492 | 0.3296 | -0.0803 |
| p3 | 0.0185 | 0.1977 | -0.1792 |
| p4 | -0.0773 | 0.1157 | -0.1930 |
| p5 | -0.0517 | -0.0070 | -0.0447 |

both-hit 样本中，B2 在 neck p2/p3/p4 的 ROI peak 多数高于 A1；但 A1 检出/B2 漏检样本中，B2 在 p3/p4 的优势消失，p4 甚至低于 A1。`neck_trace_local_contrast.png` 也显示：A1 检出/B2 漏检组里 A1/B2 neck 局部对比度曲线接近，而 both-hit 对照组中 B2 多个 neck 阶段更强。

进一步看 P4 链条：

| 指标 | A1 检出/B2 漏检 median | both-hit control median | 差值 |
| -- | --: | --: | --: |
| backbone p4 rgb_roi_peak | -0.0950 | -0.1547 | 0.0598 |
| backbone p4 ir_roi_peak | -0.0207 | -0.0075 | -0.0132 |
| fused p4 roi_peak | 0.0143 | -0.0278 | 0.0420 |
| neck p4 roi_peak | -0.0773 | 0.1157 | -0.1930 |

也就是说，问题不像是 backbone 早期已经把 smoke 完全丢掉；更像是 P4 融合之后进入 neck 多尺度传播时，一部分低对比 smoke 的响应被重排或稀释，最终在 p2/p3/p4 head 上无法保持 smoke 类别响应。

#### 6.2.4 P4 runtime ablation

对 182 个 A1 检出/B2 漏检实例，B2 的 P4 runtime ablation 显示当前 cross 强度确实会影响部分 smoke 响应：

| 参数 | 数值 |
| -- | --: |
| gamma_rgb | 0.2135009765625 |
| gamma_ir | 0.305419921875 |

| mode | max head smoke mean | median | 相对 baseline 均值变化 | >0.1 样本数 | 恢复到 conf>=0.25 样本数 |
| -- | --: | --: | --: | --: | --: |
| baseline | 0.1522 | 0.0137 | - | - | - |
| gamma_zero | 0.2066 | 0.0131 | +0.0544 | 34 | 31 |
| cross_zero | 0.1602 | 0.0059 | +0.0080 | 16 | 14 |
| rgb_cross_zero | 0.1566 | 0.0125 | +0.0043 | 7 | 7 |
| ir_cross_zero | 0.1573 | 0.0081 | +0.0051 | 13 | 12 |

`gamma_zero` 对 `low_confidence` 样本最有效：111 个低置信样本中，31 个提升超过 `0.1`；对 `no_response` 几乎无效。按尺寸看，`128-256` 和 `>=256` 的恢复更明显。这说明 P4 cross 强度参与了部分 smoke 低置信问题，但不是全部漏检的唯一原因。

#### 6.2.5 本节结论

1. **B2 的 smoke 损失主要体现为低置信度漏检，而不是单纯定位失败。**
2. **额外漏检覆盖 p2/p3/p4，多数是中小到中等尺度 smoke，不是单纯小目标问题。**
3. **关键差异不是 backbone 早期完全丢失 smoke，而是 P4 cross 后经过 neck 传播进入 detection head 时，p2/p3/p4 smoke 类别响应显著坍缩。**
4. **P4 gamma 置零能恢复部分低置信样本，说明 P4 cross 强度参与了问题，但最终机制更接近特征传播与 head 置信度重排。**

### 6.3 离线类别梯度冲突诊断

本节对应完整报告：

- `runs/detect/diagnose/gradient_conflict（离线类别梯度冲突诊断）/report.md`

离线诊断读取已有 checkpoint，不重新训练，不更新权重。固定探针集包含 198 张图像，分层如下：

| 分层 | 图像数 |
| -- | --: |
| smoke_only | 64 |
| smoke_fire | 64 |
| smoke_person | 6 |
| smoke_fire_person | 64 |

诊断对象包括 F2、D2.1、A1、B2、B8 的可用 checkpoint，参数组包括 `p4_module`、`shared_neck`、`detection_head`。主要统计类别正样本分类损失对指定参数组的梯度余弦，`conflict rate` 定义为 `cosine < 0` 的有效 batch 比例。

#### 6.3.1 Assignment 稳定性

各 checkpoint 的 smoke/fire/person 正样本数量高度稳定：

| 实验 | checkpoint | smoke 正样本均值 | fire 正样本均值 | person 正样本均值 |
| -- | -- | --: | --: | --: |
| F2 | best | 34.44 | 15.92 | 6.88 |
| F2 | last | 34.43 | 15.95 | 6.87 |
| D2.1 | last | 34.43 | 15.95 | 6.97 |
| A1 | best | 34.39 | 15.88 | 6.87 |
| A1 | last | 34.40 | 15.96 | 6.87 |
| B2 | best | 34.43 | 15.99 | 6.86 |
| B2 | last | 34.42 | 15.96 | 6.94 |
| B8 | best | 34.38 | 15.94 | 6.94 |
| B8 | last | 34.38 | 15.93 | 6.93 |

因此，B2/B8 的 smoke 问题不太可能来自 TAL 正样本分配数量突然减少。

#### 6.3.2 Shared neck 主结论

`shared_neck` 是主判断对象，因为它代表 P4 后进入多尺度融合路径的共享参数。关键统计如下：

| 实验 | checkpoint | smoke-fire mean | smoke-fire conflict | smoke-person mean | smoke-person conflict |
| -- | -- | --: | --: | --: | --: |
| F2 | best | 0.0481 | 0.4000 | 0.0757 | 0.3158 |
| F2 | last | 0.0642 | 0.4143 | 0.0967 | 0.3158 |
| D2.1 | last | 0.0454 | 0.4000 | 0.0640 | 0.2368 |
| A1 | best | 0.0414 | 0.3143 | 0.0527 | 0.3421 |
| A1 | last | 0.0563 | 0.4000 | 0.0872 | 0.3421 |
| B2 | best | 0.0390 | 0.4286 | 0.0588 | 0.3421 |
| B2 | last | 0.0537 | 0.3286 | 0.0694 | 0.3421 |
| B8 | best | 0.0249 | 0.3857 | 0.0634 | 0.3421 |
| B8 | last | 0.0425 | 0.3714 | 0.1153 | 0.3421 |

关键观察：

1. B2 的 shared neck smoke-fire conflict rate 从 best 的 `0.4286` 降到 last 的 `0.3286`，不是后期升高。
2. B8 的 shared neck smoke-fire conflict rate 从 best 的 `0.3857` 到 last 的 `0.3714`，也没有明显升高。
3. B2/B8 的 shared neck smoke-person conflict rate 基本稳定在 `0.3421`。
4. `shared_neck smoke-fire conflict rate` 与同期到最终 smoke Recall 变化的相关系数为 `-0.3621`，只能作为弱到中等相关，不能作为因果证据。

因此，离线诊断不支持“B2/B8 的 smoke Recall 后期下降主要由 shared neck 类别梯度冲突持续增强导致”。

#### 6.3.3 P4 module 与 detection head

P4 局部仍有机制线索：

| 实验 | checkpoint | P4 smoke-fire conflict | P4 smoke-person conflict |
| -- | -- | --: | --: |
| A1 | last | 0.4857 | 0.5526 |
| B2 | best | 0.4714 | 0.4474 |
| B2 | last | 0.4857 | 0.5526 |
| B8 | best | 0.5143 | 0.4737 |
| B8 | last | 0.4286 | 0.6053 |

B2/B8 在 P4 module 中的 smoke-person conflict rate 后期升高，是值得继续追踪的局部信号；但 P4 mean cosine 多数接近 0，且置信区间经常跨 0，不能单独作为强因果证据。

同时，detection head 中没有出现同步冲突增强：

| 实验 | checkpoint | head smoke-fire conflict | head smoke-person conflict |
| -- | -- | --: | --: |
| A1 | last | 0.1857 | 0.2368 |
| B2 | last | 0.1143 | 0.3158 |
| B8 | last | 0.2000 | 0.2632 |

最终检测头的类别梯度通常比 P4 module 更同向，说明 P4 局部冲突没有以简单负余弦形式扩散到 shared neck/head。

#### 6.3.4 本节结论

1. **离线诊断没有证明 B2/B8 的 smoke Recall 下降是 shared neck 或 detection head 中类别梯度冲突增强导致。**
2. **P4 module 附近存在局部 smoke-other 梯度关系不稳定，尤其 smoke-person，但信号较弱，不能单独解释最终漏检。**
3. **更合理的解释仍是 P4 Parallel Cross 改变了 smoke 特征组织和多尺度传播方式，最终影响 head 置信度排序。**
