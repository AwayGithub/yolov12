## 三、D1-D3：DMG 差分放大约束实验

本组实验继续采用第一节公平训练参数，目标是在 P2 保留 DMG 思路的基础上，约束或诱导模块学习“差分放大、共模抑制”的方向。P4 使用 A2C2f，P3 aux-head 默认启用。D1、D2.1、D3 的验证结果来自各实验目录下的 `results1.png`，D2.2 与 D2.3 来自用户验证截图。

D1-D3 的实验含义如下：

- D1（PosAlpha）：约束 DMG 的差分放大系数 `alpha >= 0`，避免模型学成“差分抑制”。
- D2.1（Init8d）：`alpha_init=1.0`，`beta_init=-0.1`。用历史 Exp-8d 的有效趋势初始化 DMG，使其从训练初期就偏向“差分放大 + 共模抑制”。
- D2.2（Init8d-Mid，已弃用）：`alpha_init=1.5`，`beta_init=-0.15`。在 D2.1 基础上提高差分放大与共模抑制强度，用于观察初始化强度敏感性；结果未优于 D2.1，后续不作为保留方案。
- D2.3（Init8d-Strong，已弃用）：`alpha_init=2.0`，`beta_init=-0.3`。进一步提高差分放大与共模抑制强度，用于验证强初始化是否继续带来收益；结果继续下降，后续不作为保留方案。
- D3（In-Sigmoid）：尝试用 InstanceNorm 后的独立 sigmoid 门控替代原始 softmax 选择，但实验显示高 IoU 指标下降，已废弃。

### 3.9 D 系列完整分析

| 实验 | 关键设置 | all mAP50-95 | fire mAP50-95 | person mAP50-95 | 结论 |
| -- | -- | --: | --: | --: | -- |
| F2 | plainP2 + A2C2f + P3 aux 基线 | 0.63529 | 0.58668 | 0.57978 | D 系列对照基线 |
| D1 | PosAlpha | **0.63668** | 0.58629 | **0.58573** | 保留为对照结果，不作为 D2/Init8d 主线 |
| D2.1 | Init8d 1.0 / -0.1 | 0.63526 | **0.58932** | 0.58236 | **D 系列最终保留方案，fire/person 综合表现最好** |
| D2.2 | Init8d 1.5 / -0.15 | 0.63224 | 0.58637 | 0.57884 | 已弃用，中等强度初始化未带来持续收益 |
| D2.3 | Init8d 2.0 / -0.3 | 0.63041 | 0.58031 | 0.57754 | 已弃用，强初始化损伤高 IoU 定位质量 |
| D3 | In-Sigmoid | 0.63295 | 0.58388 | 0.57653 | 粗检出增强但定位质量下降，已废弃 |

D1（PosAlpha）在 all mAP50-95 和 person mAP50-95 上最高，相对 F2 的 all mAP50-95 提升 +0.00139，person mAP50-95 提升 +0.00595。该结果说明正约束 `alpha` 对整体稳定性和人员目标有收益，但其 fire mAP50-95 未超过 F2，也低于 D2.1。因此，D1 保留为有效对照结果，不作为 D2/Init8d 主线的最终选择。

D2 系列的最终结论是：只有 D2.1（`alpha_init=1.0`、`beta_init=-0.1`）取得有效且稳定的收益，是 D 系列最终保留方案。D2.1 使 fire mAP50-95 达到 0.58932，是 D 系列和 F2 基线中 fire 高 IoU 指标最高的结果；person mAP50-95 也相对 F2 提升 +0.00258，且 fire/person 的 P、R、mAP50 均同步提高。D2.2（`alpha_init=1.5`、`beta_init=-0.15`）虽然仍能提高 fire 的 precision、recall 和 mAP50，但 mAP50-95 仅为 0.58637，低于 D2.1 和 F2，标记为弃用。D2.3（`alpha_init=2.0`、`beta_init=-0.3`）进一步下降，fire mAP50-95 仅为 0.58031，person recall 也相对 F2 下降 -0.00961，同样标记为弃用。该趋势说明过强的差分放大/共模抑制初始化会使模型偏向粗检出或局部响应增强，但不利于高 IoU 定位稳定性。

从任务优先级看，本项目更关注 fire/person 关键目标，尤其是火焰定位质量和人员目标稳定检出。在该口径下，D2.1 是当前 D 系列最合适的保留结果；D2.2 与 D2.3 的价值主要在于证明 Init8d 存在强度敏感性，不能简单通过增大 `alpha_init` 或降低 `beta_init` 获得更好结果，后续实验与报告不再将其作为候选主线。

D3（In-Sigmoid）不适合作为后续主线。虽然 D3 的 P/R 和 mAP50 多数高于 F2，但 all、fire、person 的 mAP50-95 均低于 F2，说明该结构更像提升粗检出能力，却损伤高 IoU 定位质量。结合 D2.2/D2.3 的下降趋势，D 系列总体表明：DMG 方向的收益需要温和约束或轻度先验，过强门控或过强初始化都会降低定位质量。

D3 仅保留为负结果记录；由于其对 all、fire、person 的 mAP50-95 均为负收益，相关 `DMGFusionINSigmoid` 实现和 `yolov12-dual-p2-dmg-in-sigmoid.yaml` 配置已从代码仓库删除，后续不再维护为可运行实验分支。此前已经证明效果不佳的 `DMGFusionV2` 与 SGMC 也同步废弃：相关模块实现、`p2_fusion=dmg_v2` 分派和 `yolov12-dual-p2-sgmc.yaml` 配置已移除，仅保留历史实验记录。
