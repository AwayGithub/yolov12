## 三、D1-D3：DMG 差分放大约束实验

本组实验继续采用第一节公平训练参数，目标是在 P2 保留 DMG 思路的基础上，约束或诱导模块学习“差分放大、共模抑制”的方向。P4 使用 A2C2f，P3 aux-head 默认启用。D1、D2.1、D3 的验证结果来自各实验目录下的 `results1.png`，D2.2 与 D2.3 来自用户验证截图。

D1-D3 的实验含义如下：

- D1（PosAlpha）：约束 DMG 的差分放大系数 `alpha >= 0`，避免模型学成“差分抑制”。
- D2.1（Init8d）：`alpha_init=1.0`，`beta_init=-0.1`。用历史 Exp-8d 的有效趋势初始化 DMG，使其从训练初期就偏向“差分放大 + 共模抑制”。
- D2.2（Init8d-Mid，已弃用）：`alpha_init=1.5`，`beta_init=-0.15`。在 D2.1 基础上提高差分放大与共模抑制强度，用于观察初始化强度敏感性；结果未优于 D2.1，后续不作为保留方案。
- D2.3（Init8d-Strong，已弃用）：`alpha_init=2.0`，`beta_init=-0.3`。进一步提高差分放大与共模抑制强度，用于验证强初始化是否继续带来收益；结果继续下降，后续不作为保留方案。
- D3（In-Sigmoid）：尝试用 InstanceNorm 后的独立 sigmoid 门控替代原始 softmax 选择，但实验显示高 IoU 指标下降，已废弃。

D1（PosAlpha）在 all mAP50-95 和 person mAP50-95 上最高，相对 F2 的 all mAP50-95 提升 +0.00139，person mAP50-95 提升 +0.00595。该结果说明正约束 `alpha` 对整体稳定性和人员目标有收益，但其 fire mAP50-95 未超过 F2，也低于 D2.1。

D2 系列的最终结论是：只有 D2.1（`alpha_init=1.0`、`beta_init=-0.1`）取得有效且稳定的收益，是 D 系列最终保留方案。相对 F2，D2.1 的 all mAP50-95 基本持平（-0.00003），但 fire/person 的 mAP50-95 分别提升 +0.00264/+0.00258；相对 F0，D2.1 的 all/fire/person mAP50-95 分别提升 +0.01218/+0.01489/+0.02239。也就是说，F0 对比证明完整结构堆叠明显有效，F2 对比则说明 Init8d 的主要边际价值集中在 fire/person，而不是 smoke 或 all 总分。

从任务优先级看，本项目更关注 fire/person 关键目标，尤其是火焰定位质量和人员目标稳定检出。在该口径下，D2.1 是当前 D 系列最合适的保留结果；D2.2 与 D2.3 的价值主要在于证明 Init8d 存在强度敏感性，不能简单通过增大 `alpha_init` 或降低 `beta_init` 获得更好结果，后续实验与报告不再将其作为候选主线。

D3（In-Sigmoid）不适合作为后续主线。虽然 D3 的 P/R 和 mAP50 多数高于 F2，但 all、fire、person 的 mAP50-95 均低于 F2，说明该结构更像提升粗检出能力，却损伤高 IoU 定位质量。

## 五、B 系列：A1 + Parallel Cross A2C2f 高层跨模态注意力实验

### 5.1 实验目标、统一训练设置与结构变量

B 系列以 A1 的 `DMGInit8d@P2 + FreAtt@P3 + P3 aux` 为基础，研究 P4/P5 高层跨模态注意力及其轻量化、残差约束、分支深度和多阶段特征聚合能否改善验证集泛化。除下表显式列出的变量外，均继承 A1 与 B2 的设置。

Parallel Cross A2C2f 将每个模态拆分为 self 与 cross 两条 `C/2` 分支。cross 分支以另一模态进入模块时的固定 cross 特征作为 K/V；默认将 `self_in/cross_in/self_out/cross_out` 四路特征拼接，经 `2C -> C` 的 `cv2` 投影后，由 learnable gamma 残差注入原特征。`cross_scale_rgb` 控制 IR guide 到 RGB query 的 cross delta，`cross_scale_ir` 控制 RGB guide 到 IR query 的 cross delta。B9 进一步加入中间阶段特征，并使用 `3C -> C` 投影。

### 5.4 结构诊断

B1 的 pcross 会替换原 A2C2f 的多阶段特征细化拓扑，而不是在原拓扑旁路轻量添加 cross attention。B1 同时改变特征流数量、concat 语义、残差形式与跨模态耦合方式，因此变量范围较大。

B1 `last.pt` 的 P4/P5 gamma 分别为 RGB `+0.21155/+0.37012`、IR `-0.20618/-0.44434`。forward hook 显示 P5 IR 残差注入强度约为原特征范数的 53%，是明显的高层负向修正。运行时缩放或关闭 P5 gamma 会进一步降低 mAP50-95；结合 B2 移除 P5 后明显恢复，说明 P5 cross 是 B1 的主要负贡献来源。

B3 证明问题不是 cross MLP 宽度过大导致的简单容量过拟合。B4 则证明单独减弱一个方向的 cross delta 也不能解决问题，并会削弱 fire 所需的跨模态补充。

### 5.5 B 系列结论

1. **主线仍保留 A1，B8 epoch190 是最接近 A1 的 B 系列节点。** A1 与 B8 的 all mAP50-95 分别为 `0.64123/0.64117`，差值仅 `-0.00006`；但 B8 smoke 仍比 A1 低 `0.00725`。
2. **B2 保留为 P4-only 对照。** B2 取得 B 系列最高 fire mAP50-95 `0.59954`，结构更简单；B8 通过增加 self/cross 深度将 overall mAP50-95 提高到 `0.64117`，但没有解决 smoke 损失。
3. **B1、B3-B7 均弃用。** P5 cross、缩窄 cross MLP、非对称 scale、低学习率加 DropPath、正值有界 gamma，以及仅增加 self 深度均未超过 B2/B8。B7 的 all Precision 虽最高，但 Recall 和 overall mAP50-95 明显下降。
4. **B9 作为多阶段聚合诊断实验继续训练。** 它用于判断 B2/B8 的 smoke 损失是否来自替换原 A2C2f 后缺少中间阶段特征聚合；在完成最终独立验证前不作结论。

### 5.6 B2 相对 A1 的 smoke 逐层 neck 诊断

为了确认 B2 的 smoke 漏检到底发生在 neck 的哪一段，而不是只看 backbone 或最终 head 的汇总输出，这里对 `A1 检出、B2 漏检` 的 182 个 smoke 目标做了逐层跟踪，并用 182 个按尺寸匹配的 `A1/B2 都检出` smoke 目标作为对照。统计位置为 neck 的六个关键节点：

- `11`: `topdown_p4`
- `14`: `topdown_p3`
- `17`: `topdown_p2`
- `20`: `bottomup_p3`
- `23`: `bottomup_p4`
- `26`: `bottomup_p5`

统计指标主要看 GT box 内的 `local_contrast`，并辅以 `roi_peak`。结果表明，B2 不是在 backbone P4 一次性把 smoke 学坏，而是在 neck 的 top-down / bottom-up 传递中把烟雾特征重组得更尖、更窄，但不够稳，最终导致分类头置信度被压低。

#### 5.6.1 漏检组的逐层变化

在 `A1 检出、B2 漏检` 的 182 个样本上，B2 相对 A1 的 `local_contrast` 中位数变化如下：

| neck 节点      |  A1 中位数 |  B2 中位数 |    B2-A1 |
| ------------ | ------: | ------: | -------: |
| topdown\_p4  | 1.03073 | 1.01768 | -0.01306 |
| topdown\_p3  | 1.10121 | 1.07390 | -0.02731 |
| topdown\_p2  | 1.08309 | 1.09561 | +0.01252 |
| bottomup\_p3 | 1.16072 | 1.14868 | -0.01204 |
| bottomup\_p4 | 1.11724 | 1.09966 | -0.01758 |
| bottomup\_p5 | 1.03928 | 1.02298 | -0.01630 |

这说明：

1. `topdown_p4 -> topdown_p3` 是第一段明显下滑点，B2 在这里就已经比 A1 弱。
2. `topdown_p2` 的对比度虽然短暂回升，但只是局部补偿，不足以恢复 smoke 的稳定语义。
3. `bottomup_p3 -> bottomup_p4 -> bottomup_p5` 才是最终压低 smoke 的关键段，B2 在这三层持续弱于 A1。

`roi_peak` 也呈现相同形态：B2 在 `topdown_p3/topdown_p2` 会抬高局部峰值，但到 `bottomup_p4/p5` 峰值回落，说明特征被加工成更尖锐但更不稳定的响应，而不是更完整的烟雾区域证据。

#### 5.6.2 对照组的逐层变化

在 `A1 与 B2 都检出` 的对照组上，B2 反而能把 neck 的中高层特征做得更强，尤其是 `topdown_p2` 和 `bottomup_p3`：

| neck 节点      |  A1 中位数 |  B2 中位数 |    B2-A1 |
| ------------ | ------: | ------: | -------: |
| topdown\_p4  | 1.03590 | 1.03362 | -0.00228 |
| topdown\_p3  | 1.13065 | 1.16114 | +0.03049 |
| topdown\_p2  | 1.09049 | 1.19491 | +0.10443 |
| bottomup\_p3 | 1.22505 | 1.28491 | +0.05986 |
| bottomup\_p4 | 1.16960 | 1.19811 | +0.02851 |
| bottomup\_p5 | 1.07466 | 1.06352 | -0.01114 |

这组结果说明 B2 并不是整体能力变差，而是它对“正常能检出的 smoke”更强，但对“低对比、容易漏检的 smoke”更容易把特征语义重组坏。这也解释了为什么 B2 在总体指标上接近 A1，但 smoke recall 反而下降。

#### 5.6.3 结论

1. **B2 的 smoke 问题主要不是 backbone P4 激活强度不够，而是 neck 的传播和重组方式变了。**
2. **漏检样本的主要损失发生在** **`topdown_p3`** **之后，并在** **`bottomup_p4/p5`** **被放大。**
3. **B2 对正常 smoke 样本的 neck 表征更强，但对低对比、32-128px 的烟雾更容易把有效响应压成高峰值、低稳定性的碎片化特征。**
4. **这支持后续继续优先尝试“恢复原始 A2C2f 的模态内深度和多阶段聚合”，而不是继续单纯增加 cross 分支深度。**

### 5.7 B9：B8 多阶段 self/cross 特征聚合

B9 以 B8 为基线，保留 P4 `self_depth=4`、`cross_depth=4`、cross MLP ratio=`2.0` 与固定原始 opposite-modal guide。唯一主要结构变化是恢复类似原始 A2C2f 的两组 ABlock 中间特征聚合。

每条 self/cross 半宽分支将 4 个 ABlock 分为两组，每组 2 个 block，并记录输入、第一组输出和第二组输出。cross 分支的中间与最终 checkpoint 使用独立可学习缩放：

```text
cross_mid_scaled = cross_in + cross_mid_scale * (raw_cross_mid - cross_in)
cross_out_scaled = cross_in + cross_out_scale * (raw_cross_out - cross_in)
```

每个模态最终拼接：

```text
self_in + cross_in + self_mid + cross_mid_scaled + self_out + cross_out_scaled = 3C
Conv(3C, C) -> gamma residual
```

RGB/IR 分别具有独立的 mid/out scale，共四个可学习标量，均初始化为 `1.0`。第二组 CrossABlock 继续接收未缩放的 raw 中间特征，scale 仅控制 checkpoint 进入最终 concat 的强度。

| 实验 | 配置                                                        |       参数量 | 训练目录                 | 状态            |
| -- | --------------------------------------------------------- | --------: | -------------------- | ------------- |
| B9 | B8 + P4 self/cross 两组中间特征 concat + 独立 mid/out cross scale | 5,250,292 | `runs/detect/train9` | GPU 3 持久化恢复训练 |

B9 用于验证 B2/B8 的 smoke 损失是否主要来自原始 A2C2f 多阶段聚合拓扑缺失。除 P4 stage concat 与 mid scale 外，其余模型和训练参数均保持 B8 不变。

### 5.8 B8 epoch190 独立完整验证

B8 在 B2 的 P4-only Parallel Cross 基础上，将 P4 A2C2f 内每条模态内分支和跨模态分支的 ABlock 深度均从 2 增加到 4，暂不恢复中间阶段 concat。训练曲线中 overall mAP50-95 的最高点是 epoch 190，曲线值为 `0.64145`。由于周期权重文件按零基 epoch 字段命名，本次明确使用 `runs/detect/train8/weights/epoch189.pt`，其 checkpoint 内部 `epoch=189`，对应训练记录中的 epoch 190；没有使用 `best.pt` 或 `last.pt`。独立验证结果保存于 `runs/detect/adr003/B8_train8_epoch190_val`。

#### 5.8.1 与 A1/B2 的差值

下表差值均为 `B8 epoch190 - 对照`。A1 现有记录没有完整分类别 P/R/mAP50，因此与 A1 的分类别对比仅使用 mAP50-95。

| 对照 |       ΔP |       ΔR |   ΔmAP50 | ΔmAP50-95 |   Δsmoke |    Δfire |  Δperson |
| -- | -------: | -------: | -------: | --------: | -------: | -------: | -------: |
| A1 | -0.00296 | -0.00150 | -0.00550 |  -0.00006 | -0.00725 | +0.00460 | +0.00247 |
| B2 | -0.00019 | -0.00099 | -0.00195 |  +0.00036 | +0.00099 | -0.00043 | +0.00052 |

B8 epoch190 相比 B2 的 overall mAP50-95 高 `0.00036`，smoke/person 分别高 `0.00099/0.00052`，但 fire 低 `0.00043`，且 overall recall 低 `0.00099`。相比 A1，它的 overall mAP50-95 仅低 `0.00006`，但 smoke 仍低 `0.00725`；fire/person 的提升无法完全抵消 smoke 损失。

#### 5.8.2 结论

1. **B8 epoch190 几乎追平 A1，并略高于 B2。** 其 overall mAP50-95 与 A1 仅差 `0.00006`，比 B2 高 `0.00036`。
2. **单纯增加 P4 self/cross 深度没有解决 smoke 损失。** smoke mAP50-95 仍比 A1 低 `0.00725`。
3. **B8 epoch190 作为 B8 唯一保留验证节点。** 后续 B9 用于验证恢复中间阶段 concat 能否进一步改善类别平衡。
