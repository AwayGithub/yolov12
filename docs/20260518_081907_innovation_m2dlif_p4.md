# 20260518_081907 Innovation: M2D-LIF P4 Local Illumination Fusion

## 1. 本轮选择的论文

- 论文标题：Rethinking Multi-modal Object Detection from the Perspective of Mono-Modality Feature Learning
- 作者/年份：Tianyi Zhao, Boyang Liu, Yanglei Gao, Yiming Sun, Maoxun Yuan, Xingxing Wei；ICCV 2025
- 论文库文件：`docs/literature_rgbt_fusion/pdfs/2025_ICCV_M2D_LIF.pdf`
- 论文库记录：`docs/literature_rgbt_fusion/README.md`、`docs/literature_rgbt_fusion/notes/2026-05-18_arxiv_github_roundup_03.md`
- GitHub 仓库：https://github.com/Zhao-Tian-yi/M2D-LIF
- 本轮阅读的代码快照：commit `210c7ca`，临时 clone 到 `C:\Users\away2\AppData\Local\Temp\codex_external_repos\M2D-LIF-210c7ca-20260518`

选择原因：M2D-LIF 是 RGB-IR object detection 工作，不是分类或纯分割方法。论文核心问题是 fusion degradation：多模态联合训练和强融合可能削弱单模态表征，导致单模态能检出的目标反而在多模态模型中漏检。这与当前项目已观察到的强跨模态注意力、SGMC、DMG v2 等方向收益不稳高度一致。相比迁移完整 M2D distillation，本轮只迁移其推理期可用、轻量、代码明确的 Local Illumination-aware Fusion。

## 2. 本轮迁移的唯一创新点

创新点名称：M2D-LIF-style P4 Local Illumination-aware Fusion (`M2DLocalIlluminationGate` + `M2DLocalIlluminationFusion`)

原论文作用：M2D-LIF 用 RGB 图像估计局部 illumination / modality weight map，在 P3/P4/P5 融合时按区域动态设置 RGB 与 IR 权重。低照、遮挡或热红外更可靠区域可偏向 IR；RGB纹理更可靠区域可偏向 RGB，从而减少固定加权或强注意力造成的 fusion degradation。

原始代码实现位置：

- `ultralytics/nn/modules/block.py:25` `LIF`：从 RGB 输入经 3 次 `Conv + AvgPool2d(2)` 生成 stride-8 的 1 通道权重图。
- `ultralytics/nn/modules/block.py:46` `LIFAdd`：将权重图按 stage 下采样到 P3/P4/P5，公式近似为 `weight_rgb = 0.5 + beta * clamp((weight - 0.31) / 0.63, max=0.5)`，`weight_ir = 1 - weight_rgb`，再做加权和。
- `model_yaml/yolov8-LIF.yaml`：在 YOLOv8 双流 backbone 的 P3/P4/P5 使用 `LIFAdd`。

为什么适合当前任务：烟雾、火焰、人员三类目标的模态可靠性随局部区域变化很大。烟雾更依赖 RGB 纹理和低对比边界，火焰和人员常依赖 IR 热结构，但热源过曝、背景热物体或 RGB 草地纹理都可能误导固定融合。P4 位于中层语义尺度，空间分辨率低于 P3，成本可控；又比 P5 保留更多目标区域信息，适合先做单点消融。

## 3. 与已有创新点的差异

已有创新点和负结果清单来自 `docs/ADR-001-dual-stream-yolov12-mf.md`、`docs/ADR-002-minimal-dual-stream-dmg-fusion.md`、`docs/ADR-003-fair-batch16-lr001-experiment-plan.md` 以及上一轮 `docs/20260517_165515_innovation_fredft_p3.md`：

- 已确认基线：P3 aux + P2 `DMGFusionInit8d(alpha_init=1.0, beta_init=-0.1)`，无 CMG/CMA。
- 已有或已否定：CMG/CMA、BidirLiCMA / Adapter @P5、SGMC、DMG v2、DMG in-sigmoid、过强 Init8d、FreDFT P3 frequency fusion。

本轮不重复上述机制。`M2DLocalIlluminationFusion` 不使用 `|RGB-IR|` 差异图，不做 FFT 频域交互，也不做跨模态 attention；它使用 RGB 原图派生的局部 illumination map 对 P4 特征执行轻量加权和。为了避免叠加多个新机制，本轮新配置不启用 `freq_fusion_stages`，只在 P4 开启 `lif_fusion_stages: [p4]`。

## 6. 预期影响

- smoke：P4 局部 illumination gate 可能在 RGB 纹理更可靠的烟雾边界区域提高 RGB 权重，帮助减少热红外弱响应导致的烟雾漏检；风险是烟雾背景亮度变化可能使 RGB 权重偏高，增加雾/云误检。
- fire：火焰通常同时有 RGB 色彩边缘和 IR 热源响应。LIF 若能在低照/强热区域偏向 IR，可能提升火焰 recall；但 P4 weighted add 替代 concat conv，表达能力比可学习 1x1 conv 弱，可能损伤高 IoU 定位。
- person：人员小目标对 RGB/IR 可靠性高度依赖场景。LIF 有机会在照明良好区域保留 RGB 轮廓，在低照区域偏向 IR 热形；风险是只用 RGB 图像估计 illumination，无法直接识别热红外传感器过曝或热干扰。
- RGB/T fusion：提供一条不同于 DMG、FreDFT、CMG/CMA 的轻量可靠性路由路径，适合验证“图像局部条件能否指导中层融合”。
- 参数量 / 计算量 / 推理速度：净增加约 23.5K 参数。新增 gate 在原图上运行三层小卷积和三次 2x 下采样，计算量低于跨模态 attention 或 FFT，但会比纯 P4 concat 略慢。

## 7. 后续实验建议

推荐训练配置：

```bash
conda run --no-capture-output -n yolov12 python train.py --input_mode dual_input --fusion_stage middle --cfg yolov12-dual-p2-m2dlif-p4.yaml --epochs 200 --batch 16 --lr0 0.01
```

推荐消融实验：

- LIF-1：`lif_fusion_stages: [p4]`，本轮配置。
- LIF-2：`lif_fusion_stages: [p3]`，只在 LIF-1 不退化时再做；注意它会和 FreDFT P3 冲突，不能同配。
- LIF-3：`lif_fusion_stages: [p5]`，用于验证高层语义处 illumination gate 是否仍有效。
- LIF-4：`lif_beta: 0.2`，观察更保守权重幅度是否减少 high-IoU 定位损伤。

推荐对比指标：

- 主指标：`results1.png` 里的 all / smoke / fire / person mAP50-95。
- 辅助指标：Recall、mAP50，判断 LIF 是否只提高粗检出。
- 训练曲线：`results.csv` 中 train/val loss gap，判断是否像强融合模块一样过拟合。
- 调试量：抽样可视化 LIF illumination map，检查明亮背景、火焰、烟雾和人员区域的权重方向。

重点风险：

- 如果 fire/person recall 上升但 mAP50-95 下降，说明 illumination gate 只提升粗响应，损伤定位质量。
- 如果 smoke 下降，可能是 RGB illumination map 对亮雾/白烟背景过敏。
- 如果 P4 LIF 负收益明显，应优先尝试更小 `lif_beta`，而不是继续堆叠 P3/P5。
