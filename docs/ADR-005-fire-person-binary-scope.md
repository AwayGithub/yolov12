# ADR-005：Fire/Person 二分类主线收束

**状态：** 已收束  
**主创新链：** `F0 -> F2 -> D2.1 -> A1 -> B2`  
**创建日期：** 2026-06-24  
**最后更新：** 2026-07-03  
**相关文档：** [ADR-003](ADR-003-fair-batch16-lr001-experiment-plan.md), [ADR-004](ADR-004-smoke-recall-improvement.md)

## 一、最终决策

1. 主论文任务从三分类收缩为 **fire/person 二分类检测**
2. 主创新链固定为：`F0 -> F2 -> D2.1 -> A1 -> B2`
3. B2 为最终模型；B1 为支线消融，不进入主链
4. Smoke 问题转为后续研究

> 在 fire/person 二分类口径下，主链 overall mAP50-95 从 F0 的 0.556 连续提升至 B2 的 0.579。

## 二、为什么收缩为二分类

ADR-004 表明 smoke 与 fire/person 存在类别竞争：B2 在 fire/person 上持续受益，但 smoke 指标难以保住。继续纳入 smoke 会让论文叙事发散。二分类重训是必要的，因为三分类与二分类不是同一优化问题。

## 三、主创新链定义

```text
F0 -> F2 -> D2.1 -> A1 -> B2
```

| 节点 | 结构变化 | 论文角色 |
| --- | --- | --- |
| F0 | 双流基线：无 P2，无 P3 aux，P4 用 A2C2f | 起点基线 |
| F2 | 补齐 P2 neck/head + P3 aux | 四尺度与辅助监督基线 |
| D2.1 | P2 用 DMGInit8d | 低层差分放大 |
| A1 | 加入 CFRA@P3 | 中层频域交互 |
| B2 | P4 用 Parallel Cross A2C2f | 高层语义交互，最终模型 |

## 四、统一实验口径

- 数据：`RGBT-3M-dual-fire-person.yaml`，`nc=2`（fire/person）
- 输入：`dual_input`，图像尺寸 `[480, 640]`
- 训练：200 epochs，batch=16，SGD，lr0=0.01，cls=0.1，seed=0，AMP 开启
- 验证：优先使用独立验证结果；F0 用 `epoch87.pt`，其余用 `last.pt`

## 五、总体网络设计

B2 是分层跨模态融合检测器，以 YOLOv12 双主干为基础，在不同层级引入不同机制：

1. **基础增强**：P2 检测层（保留高分辨率细节）+ P3 单模态辅助头（增强单模态特征质量）
2. **P2 差分放大（DMG）**：计算 RGB/IR 差异图，放大模态差异显著区域
3. **P3 频域融合（CFRA）**：跨模态 Q-K 频域响应 + 本模态 V 重标定 + 空间域 dilated FFN 细化
4. **P4 语义交互（ParallelCross）**：替换 backbone A2C2f，实现双向跨模态语义交互

设计逻辑：浅层适合差分（P2），中层适合频域（P3），高层适合语义 cross（P4）。B1 验证 P5 不适合加 cross。

其中，A1 的 P3 模块正式命名为 **Cross-modal Frequency Response Attention（CFRA）**。CFRA 不直接把一个模态的 value 注入另一个模态，而是先利用跨模态 Q-K 在频域中生成响应图，再用该响应图重标定目标模态自身的 value 特征，从而让跨模态信息承担“引导、筛选、重标定”的作用，同时保留目标模态自己的内容来源。其核心语义是：**跨模态 Q-K 负责生成频域注意力响应，目标模态 V 负责提供被增强的内容。**

## 八、最终结论

主链每一步的作用：

1. `F0 -> F2`：补齐四尺度与 P3 aux，轻微 overall 增益
2. `F2 -> D2.1`：DMG@P2，最大且最稳定的双类别增益
3. `D2.1 -> A1`：CFRA@P3，小幅中层频域增益
4. `A1 -> B2`：ParallelCross@P4，进一步提升 overall，主要改善 person

层级匹配证据：
- Perm-A/B：P2/P3 或 P3/P4 机制互换后明显退化
- P234 同构消融：DMG/CFRA 铺到多层后性能下降

论文表述：
> B2（epoch169.pt，按训练过程 `results.csv` 口径）在 fire/person 二分类任务上取得 overall mAP50-95 0.57927，主要收益来自 person；fire 与 A1 基本持平，没有发生实质性退化。
